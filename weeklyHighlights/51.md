### 1.1.1 Grok 4.6 – SpaceXAI 推出的最新一代旗舰大模型

Grok 4.6是SpaceXAI推出的1.5T参数旗舰大模型，性能逼近Claude Fable 5等顶级模型，具备50万token上下文窗口。它主打极速响应与高性价比，支持文本+图像多模态输入，擅长复杂软件开发与多步骤任务处理，已上线Grok Build、Cursor及xAI API平台。

#### 1.1.1.1 核心功能
1. 复杂任务处理：支持多步骤研究、跨代码库工作，可将宽泛产品构想快速转化为可运行原型，并能自我验证。
2. 编码工程：在CursorBench、DeepSWE等编码基准测试中接近Fable 5水平，支持漏洞修补、工程设计及代码执行。
3. 多模态推理：支持文本+图像输入，文本输出无长度限制，提供四级推理档位，50万token超大上下文窗口可处理长文本任务。
4. 工具与安全：支持工具调用、联网搜索及代码执行，安全堆栈针对漏洞修补与AI研究场景优化，保障任务安全执行。

#### 1.1.1.2 技术原理
采用1.5T参数的MoE混合专家架构，基于Grok 4.5进行补充训练，搭配改进优化器夯实训练基础。通过Grok 4.5生成并筛选推理、软件工程等领域的SFT训练数据，引入高质量工程数据提升训练质量。覆盖知识工作、编码等场景的智能体强化学习，强化模型从构想到原型的迭代能力。通过推理基础设施深度优化，实现旗舰性能与极快响应速度的平衡。

#### 1.1.1.3 应用场景
1. 日常快速编程：开发人员借助Grok Build或Cursor编辑器，实现代码快速迭代与即时反馈，提升日常编程效率。
2. 初创原型验证：初创团队可将产品构想快速转化为可运行原型，低成本验证市场需求，缩短产品孵化周期。
3. 安全漏洞修补：安全工程师利用其校准的安全堆栈，高效完成漏洞检测与修补，提升系统安全性。
4. 实时交互开发：在人机协作的设计开发流程中，极速响应特性可缩短反馈循环，提升开发协作效率。

Loomy是一款桌面AI智能体工具，此次更新推出「搭子团」和「宠物打工」两大核心功能。前者以多智能体协作模式处理复杂任务，后者通过被动积分激励降低用户使用心理门槛，助力用户从0到1快速搭建项目框架，同时提升产品使用粘性与情绪价值。

#### 1.2.1.1 核心功能
1. **搭子团多智能体协作**：将不同专长的AI助手组队，按角色分工协同完成内容创作、产品方案设计等全链路复杂任务，快速输出结构化成果。
2. **预设专业团队模板**：提供内容增长、产品发布、商务方案等4种预设团队，用户可直接调用对应团队处理垂直领域任务，无需自行组建。
3. **宠物打工被动积分激励**：用户正常使用Loomy时，桌宠会自动赚取积分并不定时反馈，反向降低用户对积分消耗的心理负担。
4. **积分体系优化**：从“消耗积分”转为“使用赚积分”，通过可变比率强化机制提升用户使用频次，增强产品持续吸引力。

#### 1.2.1.2 技术原理

2. **企业内容运营**：内容创作者使用「内容增长团队」，从选题策划、内容创作到分发策略全链路协作，提升内容生产效率与专业性。

2. 自进化能力：内置Evolver引擎，将成功协作经验固化为可复用资产，Agent可继承全网经验，实现能力持续迭代。
3. 跨端长期记忆：跨终端同步用户偏好、任务历史与工具使用习惯，无需重复交代背景，提升交互连贯性。

### 1.3.1 PAST-Bench – 普林斯顿推出的个人 Agent 的性能归因基准

PAST-Bench是普林斯顿大学团队推出的个人AI Agent递归自我改进能力基准测试，通过对比有/无记忆条件下的任务表现，判断Agent跨会话经验对后续行为的真实改进作用。它涵盖记忆、流程复用、信息搜集、更新四类能力，包含26个场景、204个任务回合，同时配套优化的Hermes+框架，为持续型Agent从经验积累到系统改进提供评估与诊断基础。

#### 1.3.1.1 核心功能
1. 多能力维度测试：覆盖记忆、流程复用、信息搜集、更新四类跨会话能力，全面评估Agent的经验复用能力。
2. 匹配对照实验：同一任务族分别运行“有记忆”和“无记忆”版本，精确归因经验带来的性能提升Δ值。
3. 机制级归因追踪：通过Mechanism-Evidence Score追踪“存储→检索→应用”完整路径，区分真实经验复用与其他干扰因素。
4. 框架适配与优化：适配多种Agent框架，并推出Hermes+框架，通过Plan、Render等五个机制提升经验复用效率与路径透明度。
5. 多模型对比测试：支持固定框架下多基础模型对比，以及固定模型下多Agent框架对比，呈现能力差异特性。

#### 1.3.1.2 技术原理

#### 1.3.1.3 应用场景
1. 个人Agent研发评估：AI研发团队可用于测试自研个人Agent的跨会话自我改进能力，定位记忆、流程复用等环节的瓶颈。
2. 框架与模型选型：企业在搭建AI助手系统时，可通过该基准对比不同Agent框架、基础模型的经验复用性能，辅助技术选型。

4. 持续型Agent落地验证：在实际部署个人AI助理前，用该基准验证其在长期使用中是否能通过经验积累持续优化服务效果。

### 2.1.1 dots.tts – 小红书联合上海交大开源的语音合成基座模型

dots.tts是小红书与上海交大联合开源的20亿参数全连续自回归语音合成基座模型，可直接在连续隐空间生成48kHz音频，在多项基准测试中取得SOTA的音色相似度与内容准确度。该模型支持零样本克隆、流式输出及低延迟双工对话，并扩展了dots.tts.edit精确语音编辑能力，提供多语言支持与多档推理速度选择。

#### 2.1.1.1 核心功能
1. **零样本音色克隆**：仅需3-10秒参考音频即可复刻该音色朗读任意新文本，支持跨语言克隆，在Seed-TTS-Eval基准上取得内容准确度与说话人相似度的SOTA表现。
2. **文本转语音合成**：提供从随机音色采样到指定说话人的高质量语音生成，基于2B参数连续自回归模型直接输出48kHz音频。
3. **流式生成与低延迟交互**：天然支持流式输出，文本前缀输入后即可逐块生成音频；1T1A双流模式下音频首包延迟低至54.4毫秒，适用于实时语音Agent与双工对话。
4. **精确语音编辑**：支持对已有录音进行文本替换、情绪调节、音高与语速修改、停顿插入或删除，且支持多项操作组合在一条指令中一次性完成，未编辑区域保持原样。
5. **多语言支持**：覆盖24种语言，在MiniMax多语言评测中平均说话人相似度达83.9，其中19个语种取得单项第一。

#### 2.1.1.2 技术原理
1. **全连续自回归架构**：摒弃传统离散Token量化方案，整条生成链路在连续隐空间运行，以自回归方式逐块预测声学片段，通过BigVGAN风格解码器还原为48kHz波形，避免离散量化带来的信息瓶颈与音色细节损失。
2. **语义化连续表征**：采用基于HoliTok设计的AudioVAE将原始波形压缩为25FPS的连续潜变量，编码器通过语义化训练在重建保真度与隐空间结构化间取得平衡，重建后说话人相似度达0.969。

4. **生成流程**：以基于Qwen2.5-1.5B初始化的LLM为中枢，直接消费BPE文本Token并输出每步隐藏状态；由18层DiT构成的自回归流匹配头，在LLM隐状态与自回归前缀条件下对下一个声学patch执行去噪生成，同时用冻结的CAM++说话人编码器提供全局x-vector保障音色一致性。
5. **后训练加速**：通过SOAR自纠正对齐提升模型稳定性；用MeanFlow蒸馏实现4步高质量生成；经简化一致性模型（sCM）压缩至2步；通过奖励感知分布匹配蒸馏（DMD）配合双时间尺度更新策略，得到自然清晰的高质量单步模型。

#### 2.1.1.3 应用场景
1. **实时语音Agent**：1T1A双流模式首包延迟低至54.4毫秒，适用于LLM驱动的实时双工对话与语音助手，为用户提供自然流畅的实时语音交互体验。

3. **全球化产品语音播报**：覆盖24种语言且保持高说话人相似度，适用于全球化产品的多语种语音播报与本地化服务，帮助企业降低多语言语音内容制作成本。

### 2.1.3 PixelRAG – 伯克利开源的视觉原生 RAG 框架

PixelRAG是伯克利SkyLab/BAIR开源的视觉原生RAG框架，摒弃传统网页文本抽取路线，将网页、PDF渲染为截图瓦片，通过LoRA微调的Qwen3-VL模型进行视觉向量检索，让模型直接读取图表、表格和版式，解决传统RAG丢失结构化信息的痛点，在开放域QA任务中精度比文本基线最高提升18.1%。

#### 2.1.3.1 核心功能
1. **多格式渲染切片**：通过Playwright将网页、PDF渲染为内容纯净的截图，按875×1024尺寸切片，保留表格、图表等结构化视觉信息，避免HTML解析丢失的布局数据。
2. **视觉向量检索**：采用Qwen3-VL-Embedding-2B模型，对截图瓦片生成单向量嵌入，构建FAISS IVF索引，支持千万级规模数据的高效近似近邻检索，精度超越文本基线。
3. **端到端QA生成**：检索到的截图直接输入VLM（如Qwen3.5-4B）生成答案，支持文本和图像混合查询，在表格理解、多模态QA场景表现突出，同时可通过图像压缩降低3倍token成本。

#### 2.1.3.2 技术原理
1. **数据采集与预处理**：从Kiwix ZIM镜像离线获取网页资产，使用Playwright无头Chrome渲染并裁剪掉导航栏等无关元素，生成纯内容截图后切片为固定尺寸瓦片，维基百科700万篇文章可生成约3000万张瓦片。
2. **嵌入模型训练**：以Qwen3-VL-Embedding-2B为基座，通过LoRA对LLM和ViT双分支微调，使用合成QA对和动态挖掘的困难负样本训练，采用InfoNCE损失优化，在单H100上3小时完成训练。
3. **检索与推理架构**：采用单向量嵌入方案控制存储成本，构建FAISS IVF索引支持增量更新；查询时将查询文本/图像生成向量，通过内积相似度检索Top-K瓦片，输入VLM时可通过Lanczos重采样降分辨率，配合微调的低分辨率阅读器平衡精度与成本。

#### 2.1.3.3 应用场景
1. **开放域知识问答**：面向智能问答系统开发者，针对包含表格、图表的网页数据，提升体育赛事数据、学术论文图表等场景的问答精度，如精准获取比赛统计数据、论文实验结果。
2. **企业文档检索**：适用于金融、咨询等需要处理PDF报表的企业，对财报、研报等文档构建视觉索引，支持通过自然语言查询表格中的营收数据、市场占比等结构化信息。
3. **智能Agent增强**：为AI Agent提供视觉检索能力，在多Hop推理任务中，如MoNaCo多文档问答，减少搜索次数并提升答案精准度，同时降低token使用成本。

1. 广告投放团队：快速生成多版本 UGC 广告素材，缩短创意测试周期。
2. 品牌内容团队：制作品牌片、产品宣传视频和社交媒体短片。
3. 独立创作者：用一个工作台完成脚本、分镜、生成和剪辑，降低视频制作门槛。
4. 开发者与自动化团队：通过 OpenClaw API 将视频生成和 Agent 流程嵌入内部工具或 SaaS 产品。

### 2.2.1 HOMIE – 香港科技大学开源的数字人视频生成框架

HOMIE是香港科技大学开源的人-物中心视频个性化生成框架，基于Wan2.1-T2V-14B骨干网络并集成Qwen3-VL多模态大模型。它能统一处理数字人、商品、Logo和文字四要素，解决人-物交互、品牌贴牌、OCR文字保真和多视角一致性四大难题，大幅降低电商带货、虚拟主播等场景的视频制作门槛。

#### 2.2.1.1 核心功能
1. 通用人-物交互视频生成：支持多主体复杂场景，在保持主体高保真度的同时实现自然的人-物互动。
2. 抽象概念个性化：无需在文本提示中明确说明，即可将Logo等抽象概念关联到语义相关物体并忠实渲染细节。
3. 多视角一致性生成：处理同一主体的多视角参考图像，生成视角连贯、主体一致的动态视频。
4. OCR文本保真生成：结合OCR地图参考，大幅提升生成视频中商品文字信息的准确性。
5. 高分辨率视频生成：支持480P单卡到720P多卡推理，满足直播带货等场景的高清需求。

#### 2.2.1.2 技术原理
HOMIE以DiT架构的文本到视频模型为骨干，集成3D VAE实现视频压缩与解码，采用流匹配范式进行训练。其核心创新包括：
1. **全局多模态引导（GMG）**：在自注意力层中注入MLLM提取的语义特征，通过对视频token的查询和键进行仿射变换，增强跨模态交互和时序一致性。
2. **模态-参考嵌入（MRE）**：通过可学习嵌入区分不同模态的输入token，同时为同一主体的多视角参考分配相同嵌入，实现主体身份绑定与多模态特征解耦。
3. **高效MLLM集成**：保留原文本编码器，通过轻量对齐网络将MLLM特征直接融入生成流程，避免了重对齐成本，同时专注于提取参考间的语义关系。

#### 2.2.1.3 应用场景
1. **电商直播带货**：商家上传商品图、品牌Logo和主播参考图，快速生成高清商品演示视频，提升直播内容制作效率。
2. **虚拟主播内容创作**：输入虚拟形象参考和场景文本提示，生成多场景互动视频，降低虚拟IP的内容制作成本。
3. **品牌营销素材生成**：基于品牌Logo和产品图，自动生成不同场景下的产品宣传视频，保持品牌视觉一致性。
4. **个性化内容定制**：用户上传个人照片和场景描述，生成包含本人形象的个性化故事视频或虚拟社交内容。
5. **产品设计展示**：结合产品多视角图，生成动态展示视频，直观呈现产品外观细节和使用场景。
