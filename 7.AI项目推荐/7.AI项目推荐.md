# 1.AI情感调节项目-FunGPT

#### 核心功能
- **FunGPT**：具备甜言蜜语模式和犀利怼语模式，可调节用户情绪。
- **GangLLM**：能根据用户输入进行杠精式回复。
- **wulewule**：帮助玩家探索《黑神话：悟空》文化内涵、提供游戏攻略。
#### 技术原理
- **FunGPT**：采用InternLM2.5系列模型，基于Transformer架构，运用多头注意力机制；使用Xtuner进行指令和全量微调；采用AWQ量化技术。
- **GangLLM**：在开源大模型上微调，基础模型为InternLLM-Chat-7B，采用特定数据进行微调训练。
- **wulewule**：模型使用xtuner在InternLM2.5微调，先进行增量预训练，再基于RAG生成的问答对数据集进行QLoRA指令微调，集成RAG和LMDeploy加速推理。
#### 应用场景
- **FunGPT**：激发创意灵感、用于娱乐消遣。
- **GangLLM**：可用于娱乐场景。
- **wulewule**：应用于游戏领域，帮助玩家深入了解游戏。

# 2.minimind-小型大模型

#### 简介
此开源项目旨在仅用3块钱成本+2小时，训练出仅为25.8M的超小语言模型MiniMind。项目开源了大模型的极简结构、数据集清洗、预训练、监督微调、LoRA微调，直接偏好强化学习、模型蒸馏算法等全过程代码，还拓展了视觉多模态的VLM：MiniMind-V。

#### 核心功能
- 提供从0开始训练语言模型的全过程代码，涵盖模型结构、数据集处理、训练算法等。
- 支持单机单卡、单机多卡训练，可使用wandb可视化训练流程，并支持动态启停训练。
- 实现多种训练算法，包括预训练、监督微调、LoRA微调、直接偏好强化学习、模型蒸馏等。
- 拓展了视觉多模态的VLM：MiniMind-V。

#### 技术原理
- **模型结构**：采用Transformer的Decoder-Only结构，如MiniMind-Dense使用RMSNorm归一化函数、SwiGLU激活函数，改用旋转位置嵌入（RoPE）；MiniMind-MoE模型基于Llama3和Deepseek-V2/3中的MixFFN混合专家模块。
- **训练算法**
    - **预训练**：让模型从大量文本中无监督学习知识点，学会词语接龙。
    - **监督微调**：对预训练后的模型施加聊天模板进行微调，使其学会对话。
    - **人类反馈强化学习（RLHF）**：使用直接偏好优化（DPO），让模型更符合人的偏好。

## Pretext – 开源 AI 前端开发工具，解决中文字布局性能瓶颈

> 周报归档：第 32 期 · 条目 2.5 · 2026-04-04 · [回看原周报](../weeklyHighlights/32.md)
> 原始周报文件：`weekly_report_20260404_142629.md`

Pretext是前React核心成员开源的纯JavaScript/TypeScript多行文本测量与布局库，通过纯算术计算绕过DOM重排，实现文本尺寸的精准测量。它支持全语言混排，性能远超传统DOM测量方案，可用于虚拟滚动、聊天气泡等场景，还能让AI无需理解CSS即可获取精确布局数据。

#### 2.5.1 核心功能
- 零DOM重排文本测量：绕过getBoundingClientRect等触发重排的API，通过纯数学计算获取文本高度和行数，避免主线程阻塞。
- 双阶段架构：prepare()完成分词、Canvas测量和缓存等预处理，layout()基于缓存做纯算术布局计算，性能提升数百倍。
- 全语言支持：兼容中文、阿拉伯语RTL、emoji混排等复杂排版场景，适配浏览器渲染差异。
- 多场景布局API：提供固定宽度换行、动态宽度逐行路由、收缩包裹等布局能力，满足不同排版需求。
- 跨端渲染支持：计算结果可输出至DOM、Canvas、SVG，即将支持服务端渲染，适配多端开发场景。

#### 2.5.2 技术原理

## Pretext – 开源 AI 前端开发工具，解决中文字布局性能瓶颈

Pretext是前React核心成员开源的纯JS/TS多行文本测量与布局库，通过纯算术计算绕过DOM重排，解决前端文本布局性能瓶颈。它支持全语言混排，预处理500段文本仅需19ms，布局计算仅0.09ms，可赋能虚拟滚动、AI生成UI等场景，让AI无需理解CSS即可获取精确布局数据。

#### 2.3.2 技术原理

#### 2.3.3 应用场景

## Markstream – 面向 AI 对话的开源流式 Markdown 渲染器

Markstream 是一组面向 AI 对话和 SSE/WebSocket token 流的开源流式 Markdown 渲染器。它让前端在模型输出尚未完成时，仍能稳定展示 Markdown 内容，尤其适合解决列表、代码块、表格等语法尚未闭合时的中间渲染状态。

#### 核心功能

- **流式 Markdown 中间态处理**：支持逐步到达的 Markdown 内容，尽量稳定地渲染未闭合的列表、代码块、表格等结构，减少 AI 回复生成过程中的闪烁、跳动和错误布局。
- **多框架组件与核心包**：覆盖 Vue 3、Vue 2、React/Next.js、Svelte、Angular，并提供 parser/core 包，便于其他前端框架或自定义渲染层接入。
- **AI 富内容扩展**：可选集成 Mermaid、KaTeX、代码高亮和代码编辑器等能力，适配模型回答中常见的图表、公式与代码片段。

#### 技术原理

Markstream 将增量 token 流转化为可持续更新的 Markdown 解析状态，在每次新内容到达时处理尚不完整的语法结构，而不是等待整段回复结束后再一次性渲染。组件层负责把解析结果映射为不同框架的 UI，核心解析层则可独立接入其他渲染环境。通过将流式解析、状态维护和富内容渲染拆分，应用可以在长回答生成期间持续输出可读内容，并在结构闭合后平滑更新最终结果。

#### 应用场景

- **AI 聊天与智能客服**：在 SSE 或 WebSocket 对话中实时展示模型回复，避免未闭合 Markdown 导致的内容错位。

- 细粒度验证评分：利用评分Token的完整logits分布计算连续期望值，替代粗糙离散打分，显著降低平局率，保留模型不确定性信息。
- 测试时Best-of-N选择：通过Probabilistic Pivot Tournament算法将排序成本从O(N²)降至O(Nk)，以线性成本从多条候选轨迹中筛选最优解，实现低成本自我验证。
- 实时进度跟踪：对Agent执行的每一步输出细粒度分数，可离线复盘完整轨迹，也可在线监测并提前终止无望任务，及时节省计算资源。
- 强化学习密集奖励：作为可插拔的密集奖励信号，接入SAC或GRPO等算法，提升离线/在线RL算法的样本效率，解决稀疏奖励的信用分配难题。
- 多模态输入支持：原生支持文本、图像和视频输入，统一验证代码Agent、VLM Agent与机器人视觉rollout，适配多领域任务需求。

#### 2.1.4.2 技术原理
- 概率化细粒度评分：将传统离散评分改为利用评分Token的完整logits分布计算期望值，模型在1–20区间输出分数，提取各Token的logprob后加权求和并归一化到[0,1]，避免单一离散值导致的高平局率与信息损失。
- 三维验证扩展架构：验证可在粒度、重复、分解三个维度独立扩展，增加评分Token数量提升正负样本分离度，多次独立评估取平均降低方差，将评估拆分为Specification、Error、Output等子准则分别打分后聚合，减少提示偏见。
- 概率锚点锦标赛（PPT）算法：先通过环状对比获得初始胜率选出top-k锚点，随后非锚点仅与锚点对比、锚点间相互较量，最后基于Bradley-Terry模型聚合胜负关系排序，将验证预算集中在不确定的头部候选。
- 跨模态偏好建模：连续奖励经Bradley-Terry模型转换为成对偏好概率，支撑可靠的候选比较，框架统一处理多模态输入，输出测试时排序、进度跟踪、RL密集奖励三类信号，实现零样本通用验证。

#### 2.1.4.3 应用场景
- 代码Agent验证：在Terminal-Bench和SWE-Bench等编程基准中，对多条代码生成轨迹进行Best-of-N筛选，以低成本选出可编译、可运行且符合需求的最优代码方案。
- 机器人任务评估：在RoboRewardBench等机器人基准中，对视觉-动作rollout进行细粒度打分，判断任务完成度与动作合理性，超越专用机器人奖励模型的评估效果。
- 医疗Agent审核：在MedAgentBench上验证医疗诊断或用药建议的准确性，确保Agent输出符合医学规范与安全标准，降低医疗AI的决策风险。
- 强化学习效率提升：作为可插拔的密集奖励信号替代稀疏0/1奖励，接入SAC或GRPO等算法，显著提升机器人与数学推理任务的RL样本效率，减少训练资源消耗。
- Agent进度监控与优化：对Agent执行的每一步实时输出验证分数，绘制任务进展曲线，及时终止无望的rollout以节省计算成本，同时为Agent行为优化提供数据支撑。

## huashu-excel – 花叔开源的 AI 数据分析 Skill

> 周报归档：第 54 期 · 条目 item-e1f5dfe1aa · 2026-08-28 · [回看原周报](../weeklyHighlights/54.md#item-e1f5dfe1aa)
> 原始周报文件：`weekly_report_20260828_092015.md`

这是一款开源的AI数据分析Skill，通过体检、清洗、对齐、分析、对账、交付、验图、质控八步流程，解决AI做数据分析时算错不报错的问题。它用openpyxl读取原始单元格识别结构陷阱，以表内合计行当校验和对账，支持多格式报告输出，让AI分析结果可追溯、可验证。

#### 2.1.11.1 核心功能
1. **数据体检**：用openpyxl读取原始单元格，在处理数据前识别表头错位、合并单元格、小计行混入等结构隐患，避免信息损毁后误判。
2. **数据清洗**：将脏表转化为规范分析表，生成可审计、可回放的清洗脚本，记录每一步对数据的影响行数。
3. **需求对齐**：先摸底数据特征和外部行业基准，再与用户确认真实需求和分析口径，避免无效分析。
4. **数据分析**：扫描辛普森悖论、幽灵分组、小基数等常见数据陷阱，将数据发现推导至业务结论层面。
5. **数字对账**：拿清洗后的明细与表内自带的“合计”行交叉验证，揪出手填错误和口径差异，确保数据准确。
6. **独立质控**：指派未参与分析的独立Agent从原始数据重算，验证结论可靠性，避免系统性错误。

#### 2.1.11.2 技术原理
采用多Agent协作架构，依次模拟领域专家、数据分析师、质控等角色完成分析全流程。底层以openpyxl为核心读取Excel原始单元格，保留格式、合并单元格等元数据；基于Panko电子表格错误研究、ICAEW《Financial Modelling Code》构建错误检测规则，实现行数守恒、总和守恒校验。图表生成遵循Cleveland & McGill感知精度阶梯，优先选用高感知精度的视觉编码；报告输出采用自包含HTML设计，内联SVG图表，无需外部资源即可离线访问。

#### 2.1.11.3 应用场景
1. **日常运营复盘**：运营人员每日获取前一日运营数据，通过工具自动完成体检、清洗、分析、对账，在早会前输出带口径声明的数据波动归因报告。
2. **销售业绩分析**：销售管理人员上传百万行交易明细，工具自动识别新品增长、老品下滑等结构性问题，输出可直接呈报管理层的HTML分析报告。
3. **财务预算审查**：财务人员分析企业或市政预算表，工具通过外部基准对账发现列名口径陷阱，给出专业的委员会级解释。
4. **HR薪酬诊断**：HR处理数万份薪酬问卷，工具在控制行业、学历、工龄等变量后计算性别薪酬差距，并明确标注分析边界。
5. **数据审计交接**：数据处理人员将脏表清洗为规范格式，同时生成可回放的清洗脚本，方便后续工作的追责与流程复用。

## zg – Zvec AI 开源的本地优先统一检索基础工具

zg（zvec-grep）是Zvec AI开源的本地优先统一检索工具，面向开发者与AI Agent。它整合ripgrep精确匹配、BM25词法检索与向量语义检索能力，实现从模糊语义探索到精确定位的完整检索链路，所有操作默认在本地完成，兼顾隐私与检索效率。

#### 2.1.1.1 核心功能
1. 多模式统一检索：融合语义检索、BM25、ripgrep精确匹配，支持从模糊意图到精确定位的完整检索流程。

3. 结果智能排序：通过RRF算法融合多路召回结果，按相关性排序并去重，减少无效信息干扰。
4. 内容结构化处理：自动识别代码符号层级、文档章节结构，保留元数据，便于精准定位。
5. AI Agent原生集成：支持MCP协议，可直接对接Codex、Claude Code等Agent，无需额外解析。
6. 本地优先索引：预建本地语义与BM25索引，支持增量更新，复用索引提升检索效率。

#### 2.1.1.2 技术原理
采用本地优先架构，内置轻量端侧Embedding模型处理语义转换；整合ripgrep实现正则精确匹配，BM25算法完成词法检索，向量数据库存储语义索引；通过RRF（Reciprocal Rank Fusion）算法融合多路召回结果，实现统一相关性排序；基于MCP（Model Context Protocol）与AI Agent交互，自动完成工具调用与结果解析；支持本地索引增量更新，无需每次搜索遍历文件系统。

#### 2.1.1.3 应用场景
1. 开发者代码探索：开发者面对陌生代码库时，以自然语言提问（如“用户偏好恢复逻辑”），快速定位相关代码实现。
2. AI Agent任务支撑：AI Agent处理跨文件代码分析、文档问答任务时，通过zg快速获取精准关联的本地内容，减少无效搜索。
3. 跨格式文档检索：同时检索本地代码、技术文档、结构化数据，统一呈现关联结果，便于技术研究与资料整合。
4. 代码架构分析：针对大型项目的架构问题，通过语义检索关联跨模块代码，辅助理解系统设计逻辑。
5. 隐私优先的本地检索：对数据隐私要求高的场景，所有检索流程在本地完成，无需上传数据至第三方服务。

Headlong是Laude Institute开源的AI Agent微框架，核心仅约1万行Bash脚本，主打持久主体性，Agent无需唤醒或定时任务，能像人类内心独白般持续自主思考、自我驱动。它支持跨平台团队协作，可自主诊断Bug、提交修复代码，还能通过Docker沙箱隔离风险，兼具易用性与安全性。

#### 2.1.7.1 核心功能
1. 持久主体思考：Agent永不休眠，持续自主生成想法，人类消息作为观察注入思维流，由Agent自主决定是否及何时回应。
2. 多团队协作支持：单个Agent对接Slack、Telegram等平台，团队共享同一思维流，Agent可主动连接成员、推送关键信息。
3. 完整轨迹记录：通过traj工具以追加式jsonl DAG格式记录Agent所有思维与行动，支持版本回溯与分支实验。
4. 分层上下文压缩：采用指数级衰减分辨率保留全轨迹，近期内容完整呈现，旧内容逐步摘要，兼顾上下文窗口限制与细节检索。
5. 自我迭代优化：Agent可fork代码库自主修改、测试，成功则合并回主分支，Laude已采纳其50+个修复与优化提交。
6. 多模型兼容与沙箱安全：通过统一CLI支持Anthropic、OpenAI等多LLM提供商，默认用Docker沙箱隔离生成代码，保障主机安全。

#### 2.1.7.2 技术原理
1. 持久主体性架构：核心为无限循环的Thinker调度器，持续调用LLM生成下一个思考步骤，外部输入以观察形式异步注入思维流，无人交互时思考速率指数级衰减以控制token成本。
2. Shellm递归语言模型：以Bash为核心工具语言，LLM直接生成Bash命令，通过管道、文件与环境变量组合原生工具，形成“思考-执行-观察”的递归闭环，无需额外工具抽象层。
3. DAG轨迹存储系统：思维与行动记录为有向无环图结构的jsonl文件，支持fork/merge操作，为Agent提供完整可追溯的生命周期记忆，也为自我改进提供版本控制基础。
4. 分层上下文投影机制：context工具基于轨迹生成LLM输入上下文，通过多级摘要实现指数级衰减分辨率，层级同时作为索引，Agent可快速检索原始历史细节。
5. Docker沙箱执行：默认将Agent生成的Bash代码在容器内运行，通过shellm-docker工具实现资源隔离，容器复用机制降低重启开销，非Docker环境需显式确认以规避风险。

#### 2.1.7.3 应用场景
1. 7×24智能代码运维：开发团队部署Agent持续监控代码库，可在非工作时段自主发现Bug、编写修复代码、运行测试并提交版本，全程无需人工介入。
2. 跨团队协作中枢：企业团队将Agent接入Slack、Telegram，作为共享数字同事汇总项目进度、主动连接相关成员，打破信息壁垒，提升协作效率。
3. 基础设施主动运维：运维团队利用Agent持续读取服务器日志与指标，自主识别异常模式，在隔离容器内执行修复脚本，实现从被动告警到主动自愈的转变。
4. 个人知识深度管理：研究者或学习者用Agent持续阅读、摘要与关联分散信息，按兴趣自主建立知识优先级，主动推送重要发现，构建可检索的个人知识轨迹。
5. 开源社区自动维护：开源项目维护者借助Agent自动分类Issue、审查PR、更新文档、回复常见问题，7×24小时保障项目健康度，减轻人工维护负担。
